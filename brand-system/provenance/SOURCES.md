# Source and approval ledger

## Sole active mascot master

- Repository file: `assets/mascots/masters/crow-mascot-v3.png`
- Role: sole active mascot identity for CrowClaw, Crow-GodMod3, CrowQuant,
  CrowNest, CrowMemory, CrowFlix and future Crow products
- Required traits: naturally proportioned adult-crow anatomy, black feather
  structure, integrated biomechanical cybernetics, cyan/blue/ultraviolet
  signal light, exactly three eyes and an unmistakable elongated corvid beak
- Allowed product variation: crop, background and approved cool-accent
  emphasis only
- Protection: do not overwrite; proposed revisions require a versioned sibling
  file and explicit approval

## Inactive legacy/reference material

The original Three-Eyed Crow reference and every earlier head-only, humanoid,
companion/pet, v1 and v2 file remain physically intact for provenance,
comparison and historical audit. Their earlier approval status has been
superseded by `crow-mascot-v3.png`.

These files must not be deleted, overwritten, silently substituted for the
active master, attached as active identity references, blended into new mascot
work or otherwise reactivated.

## Generated derivatives

Current signal marks, product hero images, banners, icons and layout exports
must derive from `crow-mascot-v3.png`. Product variants may change crop,
background and approved cool-accent emphasis only.

Any derivative built from an earlier head, humanoid or companion/pet file is
an inactive legacy derivative until it is rebuilt from the v3 master. Retaining
such a file for historical audit does not make it active.

The Crow Signal fonts and Crow Talon cursors are generated locally from
original source geometry in this repository. They consume no third-party font
or cursor binaries.
